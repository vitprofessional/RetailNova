## খ. নিয়ম (সব মোবাইল পাতায় বাধ্যতামূলক)

### ১. ফন্ট — একটাই
- UI, input, বোতাম, রিপোর্ট, প্রিন্ট, PDF/ছবি — সব জায়গায় `var(--rn-font-family)` = `"Hind Siliguri", "Noto Sans Bengali", system-ui, sans-serif`।
- `localization.blade.php`-এর Noto Bengali-র `body/input/...` ওভাররাইড, `new-sale.css` ও `retailnova-shell.css`-এর আলাদা font-family, মোবাইলে `Inter`/`Lato` — সব সরাতে হবে (ডেস্কটপ থিমের নিজস্ব হেডিং ফন্ট থাকলে শুধু ডেস্কটপে)।
- Hind Siliguri ৪টা ওজন লোকাল (400/500/600/700) — অন্য কোনো ওজন ব্যবহার নয়।

### ২. লেখার মাপ — ৭টা ধাপ, এর বাইরে নয়
| টোকেন | মাপ / ওজন / line-height | কোথায় |
|---|---|---|
| `--rn-fs-hero` | ৩০ / 700 / 1.15 | হোম আর পাতার একটাই প্রধান টাকা |
| `--rn-fs-title` | ২১ / 700 / 1.25 | হেডারের শিরোনাম |
| `--rn-fs-amount` | ১৮ / 700 / 1.25 | কার্ডের টাকা, সামারির সংখ্যা |
| `--rn-fs-heading` | ১৭ / 600 / 1.35 | কার্ডের নাম, সেকশন শিরোনাম |
| `--rn-fs-body` | ১৬ / 500 / 1.5 | সাধারণ লেখা, input, বোতাম (বোতাম 700) |
| `--rn-fs-label` | ১৪ / 500 / 1.45 | লেবেল, উপশিরোনাম, তারিখ, চালান নং |
| `--rn-fs-tag` | ১৩ / 700 / 1.2 | ট্যাগ/চিপ, নিচের মেনুর লেবেল |
- কোথাও ১৩px-এর নিচে নয়। পাতাভিত্তিক `font-size` লেখা নিষেধ — শুধু টোকেন।

### ৩. সংখ্যা ও টাকা
- একটাই helper (`LocalizedNumber`) ও Blade component `<x-m.money>`/`<x-m.qty>`: bn-এ বাংলা অঙ্ক, en-এ ইংরেজি; **দুই ভাষাতেই লাখ-গ্রুপিং** (১,২৫,৮৮০ / 1,25,880); দশমিক শুধু ভগ্নাংশ থাকলে; ঋণাত্মক "−৳৫০০"।
- সব টাকা/সংখ্যা/তারিখ/চালান নং: `white-space: nowrap; font-variant-numeric: tabular-nums;` — **কখনো দুই লাইনে ভাঙবে না**।
- জায়গা কম হলে: `<x-m.money fit>` — JS (ResizeObserver) ধাপে ধাপে ছোট করবে hero 30→22, amount 18→15; তার পরেও না ধরলে লেবেল উপরে আর টাকা নিচে এক কলামে নেমে যাবে।
- সামারি বার: ৩টা মান — প্রতিটা সর্বোচ্চ `--rn-fs-amount` (১৮px), hero মাপ নয়। ৪টা হলে ২×২।
- তারিখ: dd/mm/yyyy (bn অঙ্কে), সময় "সকাল/দুপুর/বিকাল/রাত ১০:৫৮"; input-এ `inputmode="decimal"`, placeholder "০" (bn) / "0" (en), "0.00" নয়।

### ৪. ফাঁকা জায়গা — ৪-এর গুণিতক
- স্কেল: ৪ · ৮ · ১২ · ১৬ · ২০ · ২৪ · ৩২।
- **পাতার gutter = ১৬px, সব পাতায়।** সব মোবাইল কনটেন্ট `.rn-m-page` র‍্যাপারের ভেতরে; শুধু র‍্যাপারই পাশের padding দেবে, ভেতরের কার্ড/সেকশন নিজে পাশের margin/padding যোগ করবে না।
- কার্ড: ভেতরে ১৬px padding, রেডিয়াস ১৬, কার্ডের মাঝে ১২px।
- **কার্ডের ভেতরে কার্ড নিষেধ** — এক স্তর। ভেতরে ভাগ লাগলে ১px লাইন বা ১২px ফাঁক।
- সেকশন শিরোনাম: কার্ডের বাইরে হলে উপরে ২০, নিচে ৮; কার্ডের ভেতরে হলে কার্ডের padding মেনে।
- তালিকার সারি: উপর-নিচে ১২px; সারির মাঝে ১px লাইন `--rn-line`।
- পাতার নিচের জায়গা শুধু `.content-page`-এর `--rn-bottom-reserve`-এ থাকবে: নিচের ট্যাববার + safe area + ১৬px; ট্যাববারের বদলে sticky action bar থাকলে তার উচ্চতা + safe area + ১৬px; POS-এর মতো দুইটি fixed bar থাকলে দুটির উচ্চতা + safe area + ১৬px। তালিকা ও ফর্মে অতিরিক্ত bottom padding নয়; FAB থাকলে শুধু তালিকার শেষে ৫৬px।
- কোনো স্ক্রলযোগ্য পাতায় শেষ কনটেন্ট থেকে সবচেয়ে কাছের fixed নিচের বারের দূরত্ব ২৪px-এর বেশি হলে অডিট ব্যর্থ হবে (FAB থাকলে ৭২px)। কনটেন্ট viewport-এর চেয়ে ছোট হলে document-এ অপ্রয়োজনীয় scroll থাকতে পারবে না।

### ৫. লেখা কাটা/ভাঙা
- লেবেল, চিপ, ট্যাগ, বোতাম, টাইল লেবেল: এক লাইন (টাইল লেবেল সর্বোচ্চ ২); ভাঙার বদলে `…` আর পুরো লেখা `title`-এ।
- পণ্য/কাস্টমারের নাম: সর্বোচ্চ ২ লাইন (`-webkit-line-clamp: 2`)।
- টেবিলের মতো "লেবেল : মান" সারি: লেবেল বাঁয়ে (সর্বোচ্চ ৪৫%), মান ডানে nowrap।

## গ. প্রিন্ট, PDF ও শেয়ার — নতুন কাঠামো

**ডকুমেন্ট:** বিক্রির চালান, কেনার চালান, কোটেশন, সার্ভিস ইনভয়েস, বিক্রি/কেনা ফেরত, কাস্টমার/মহাজনের খাতা (বাকির হিসাব)।

**টেমপ্লেট (প্রতি ডকুমেন্টে একটাই ডেটা, তিন মাপ):** `resources/views/documents/{type}.blade.php` + shared partials; মাপ `a4`, `thermal80` (৭২মিমি প্রিন্টযোগ্য), `thermal58` (৪৮মিমি)।
- প্রতিটা মাপে নিজের `@page { size; margin }` আর প্রিন্ট CSS; অ্যাপের শেল/মেনু কখনো প্রিন্টে আসবে না।
- লেখা আর অঙ্ক বর্তমান ভাষা অনুযায়ী; কোনো হার্ডকোড ইংরেজি নয়; দোকানের লোগো, নাম, ঠিকানা, ফোন; পেমেন্টের ধরন; বাকি থাকলে আলাদা করে।
- **QR কোড লোকালি তৈরি** (PHP লাইব্রেরি বা লোকাল JS) — বাইরের API নয়।
- দোকানের সেটিং: ডিফল্ট কাগজ (A4 / ৮০ / ৫৮), রিসিটের নিচের লেখা।

**প্রিন্ট বোতাম:** নিচের শিট থেকে মাপ বাছাই → `documents.print` route (`?size=thermal80&autoprint=1`) নতুন পাতায় → লোড হলে `window.print()`। শেষ বাছাই মনে রাখবে।

**PDF আর ছবি — ব্রাউজারেই তৈরি:** সার্ভারের DomPDF বাংলা যুক্তাক্ষর ঠিকমতো জোড়া দিতে পারে না, তাই ব্যবহার করবে না।
- একই প্রিন্ট টেমপ্লেট লুকানো iframe-এ রেন্ডার → `html2canvas` (লোকাল vendor) দিয়ে ২x ছবি →
  - **ছবি:** PNG (থার্মাল মাপে ৫৭৬px চওড়া) — হোয়াটসঅ্যাপে পাঠানোর জন্য সেরা;
  - **PDF:** `jsPDF` (লোকাল vendor) দিয়ে ঠিক পাতার মাপে (A4-এ দরকারে একাধিক পাতা)।
- ফাইলের নাম: `{দোকান}-{চালান নং}.pdf/.png` (ASCII-নিরাপদ)।

**শেয়ার:** "শেয়ার" চাপলে নিচের শিট — "ছবি হিসেবে পাঠান" · "PDF হিসেবে পাঠান" · "প্রিন্ট"।
- `navigator.canShare({files})` সত্য হলে `navigator.share({files:[file], title, text})` (Android Chrome-এ হোয়াটসঅ্যাপ/মেসেঞ্জার সরাসরি আসে)।
- না হলে ফাইল ডাউনলোড আর টোস্ট "ফাইল সেভ হয়েছে — হোয়াটসঅ্যাপে সংযুক্ত করুন"।
