# Retail Nova — মোবাইল ডিজাইন নিয়ম (ফাইনাল: টিল)

রেফারেন্স ছবি: `docs/mockups/` (README দেখো)। কোনো পাতা বানানোর আগে মিল আছে এমন মকআপ খুলে দেখবে।

## পাতার ধরন → কোন মকআপ
- **তালিকা** (যেকোনো রেকর্ডের তালিকা) → 09 + 09b: টিল হেডারে সার্চ + পিরিয়ড চিপ; নিচে ৩ সংখ্যার সামারি কার্ড; তারিখ অনুযায়ী গ্রুপ শিরোনাম; প্রতিটা রেকর্ড কার্ড (উপরে নাম+উপশিরোনাম+টাকা, নিচে লাইন দিয়ে আলাদা ট্যাগ/অবস্থা/›); ফিল্টার নিচ থেকে খোলা শিট (রিসেট + ফিল্টার করুন)।
- **ট্যাবসহ তালিকা** (স্টক, অবস্থা অনুযায়ী) → 05: সামারি কার্ড, সেগমেন্ট ট্যাবে সংখ্যা, ডানে-নিচে "+ নতুন" FAB।
- **ফর্ম** (যোগ/এডিট) → 10: এক কলাম; বিষয় অনুযায়ী সাদা কার্ডে ভাগ (কার্ড শিরোনাম); ছোট দুই ঘর পাশাপাশি; লেবেল ঘরের ওপরে, বাধ্যতামূলক ঘরে লাল *; কম দরকারি ঘর "আরও তথ্য" ভাঁজে; নিচে আটকে থাকা বাতিল (১ ভাগ) + সেভ করুন (২ ভাগ)।
- **বিস্তারিত / ইনভয়েস** → 04: উপরে অবস্থা (টিল হেডার, বড় সংখ্যা), সাদা রিসিট কার্ডে লাইনগুলো, সর্বমোট টিল রঙে, নিচে প্রিন্ট/এসএমএস/শেয়ার/PDF আইকন সারি, তারপর প্রধান কাজের বোতাম।
- **রিপোর্ট** → 07: হেডারে পিরিয়ড সেগমেন্ট + ডাউনলোড; ২×২ স্ট্যাট কার্ড (রঙিন বিন্দু + লেবেল + সংখ্যা); চার্ট কার্ড; টপ তালিকা কার্ড। চওড়া রিপোর্ট টেবিল → প্রতিটা সারি কার্ড।
- **নিচের শিট** (দ্রুত কাজ, যেমন বাকি আদায়) → 06।
